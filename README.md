🚀 Overview

LedgerLens is an AI-powered financial analysis web app that helps users analyze bank statement PDFs instantly.

Upload your bank statement and LedgerLens will:

✅ Extract transactions automatically
✅ Categorize expenses intelligently
✅ Identify spending patterns
✅ Simplify financial tracking
✅ Present data in a clean dashboard

Built during CODEFLOW2026 Hackathon ⚡
